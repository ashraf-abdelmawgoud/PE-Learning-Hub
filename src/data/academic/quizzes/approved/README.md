# بنوك الأسئلة المعتمدة أكاديمياً (Approved Question Banks)
## منصة OloomSport — علوم الرياضة

هذا المجلد مخصص حصرياً لبنوك الأسئلة التي اجتازت دورة التحكيم الأكاديمي الكاملة وحصلت على اعتماد صريح وموثق (`approvalStatus: 'approved'`).

### الوضع الحالي:
- **لا توجد أي أسئلة جديدة معتمدة أكاديمياً في هذه المرحلة.**
- يُحظر إضافة أو نشر أي ملف هنا دون مراجعة أكاديمية موثقة من أستاذ المادة، وتوثيق اسمه وتاريخ اعتماده والمرجع العلمي بدقة.
- يجب تسجيل أي بنك يتم اعتماده مستقبلاً في ملف `governanceManifest.ts` مع الهاش التوافقي الصارم لمحتواه.
